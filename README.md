项目一：企业内部资源预约管理平台 | 前后端分离分布式预约平台
技术栈：SpringBoot3.4、Spring Cloud Alibaba、Nacos、RocketMQ、MySQL、Redisson 项目背景：面向企业内部会议室资源的预约审批平台，完成分布式改造，支持多实例集群部署。 核心职责：负责预约核心模块开发，设计并发预约冲突控制方案，实现消息异步通知能力。 技术亮点：采用Redisson分布式锁+MySQL行锁双重机制解决多实例并发预约冲突；基于Nacos实现服务注册发现；利用RocketMQ异步发送预约通知，削峰解耦，提升系统稳定性。

项目二：原生ReAct智能Agent
技术栈：Python、pytest 项目背景：自研轻量智能Agent，无LangChain重型框架依赖，底层可控便于安全审计。 核心职责：手写ReAct主循环，定义工具调用协议，实现文件访问安全控制与工程化能力。 技术亮点：实现网页搜索、安全文件读取工具；增加上下文摘要压缩、JSON断点续跑、轮转日志、爬虫节流缓存；开发路径穿越防护模块；编写pytest单元测试，覆盖协议解析与安全校验，支持自动化回归。

项目三：离线统计与文件导出服务
技术栈：SpringBoot2.7、EasyExcel、Quartz、Redis、MySQL 项目背景：定时任务驱动的离线报表导出服务，支撑业务大批量数据统计与文件下载。 核心职责：设计定时任务调度、大数据量导出方案，优化内存占用与任务异常处理。 技术亮点：Quartz实现分布式定时任务，防止任务重复执行；EasyExcel流式读写，避免OOM；Redis缓存统计中间结果，降低数据库压力；任务状态持久化，支持失败重试。
